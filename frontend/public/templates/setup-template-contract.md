# Setup Spreadsheet Contract (V1)

Required tabs and columns:

1. `organizational_structure`: `code`, `name`
2. `departments`: `code`, `name`, `org_code`
3. `cost_centers`: `code`, `name`, `department_code`
4. `job_roles`: `code`, `name`
5. `schedules`: `code`, `name`, `start_time`, `end_time`
6. `employees`: `external_id`, `name`, `department_code`, `schedule_code`

Time format: `HH:mm`
